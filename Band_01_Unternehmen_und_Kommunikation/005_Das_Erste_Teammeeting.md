# Fachwortschatz

| Ausdruck | Erklärung |
|-----------|-----------|
| entkoppeln | Komponenten möglichst unabhängig voneinander gestalten |
| der Zielkonflikt | Situation, in der sich zwei sinnvolle Ziele gegenseitig beeinflussen |
| die Randbedingung | Rahmenbedingung, unter der eine Entscheidung gilt |
| nachvollziehbar | logisch verständlich und begründbar |
| der Grundsatz | allgemeines Leitprinzip |
| der Gewöhnungseffekt | Dinge werden mit der Zeit selbstverständlich und daher weniger kritisch betrachtet |
| unvoreingenommen | ohne vorgefasste Meinung |
| vorbereitend | als Vorbereitung auf spätere Arbeitsschritte |
| etwas festhalten | schriftlich dokumentieren |
| etwas begründen | eine nachvollziehbare Erklärung geben |
| das Leitprinzip | grundlegende Orientierung für Entscheidungen |
| der Gestaltungsspielraum | Bereich, in dem Entscheidungen frei getroffen werden können |

# Grammatik im Kontext

## Abschwächende Formulierungen

In technischen Besprechungen werden Aussagen häufig bewusst vorsichtig formuliert.

Statt:

> Das ist falsch.

hört man eher:

- Ich bin mir nicht sicher, ob ...
- Ich würde das etwas anders sehen.
- Das sollten wir noch einmal überprüfen.
- Könnte es sein, dass ...?
- Unter diesen Voraussetzungen würde ich eher ...

Solche Formulierungen fördern eine sachliche Diskussion und vermeiden unnötige Konfrontationen.

---

# Kulturelle Hinweise

In vielen deutschen Entwicklungsteams wird großer Wert auf eine **offene Diskussionskultur** gelegt. Gute Argumente zählen mehr als Hierarchien. Auch neue Mitarbeitende werden ausdrücklich ermutigt, Fragen zu stellen und bestehende Annahmen zu hinterfragen.

Auffällig ist außerdem die klare Trennung zwischen der Kritik an einer Idee und der Kritik an einer Person. Unterschiedliche Meinungen gelten als normal und oft sogar als Voraussetzung für gute technische Entscheidungen.
