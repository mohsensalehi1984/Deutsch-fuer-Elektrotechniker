## 📖 About

**Deutsch für Elektrotechniker** is an open-source project aimed at helping engineers develop professional German communication skills through realistic workplace dialogues.

Unlike traditional language textbooks, this repository focuses on authentic conversations that occur in engineering companies, research laboratories, universities, startups, and industrial environments throughout German-speaking countries.

The project is maintained as an **Obsidian knowledge base**, allowing easy navigation through linked concepts, technical vocabulary, and engineering topics.

Every dialogue is **AI-generated**, carefully reviewed, and written to resemble natural German used by native engineers in professional settings.
